# Barbearia 7 de Setembro

Site institucional demonstrativo criado em HTML, CSS e JavaScript.



## Antes de publicar

No `index.html`, altere:
- telefone/WhatsApp
- Instagram
- endereço
- horários
- preços
- textos
- link do WhatsApp

As fotos do site usam imagens externas do Unsplash. Para um projeto definitivo, substitua pelos arquivos reais da barbearia.

## Recursos

- layout responsivo
- menu mobile
- barra de progresso
- animações de entrada
- contadores animados
- carrossel de cortes com autoplay e swipe
- efeito de cursor
- parallax
- cards com hover
- seção de preços
- depoimentos
- chamada para WhatsApp
- área de contato
